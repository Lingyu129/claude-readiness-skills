# Claude Mac 环境检查

帮助用户判断本机 Claude Desktop、Claude Code 和相关网络设置是否可用、稳定，并在用户要求修改时完成最小范围的配置与复测。把「网络能连通」「断线时不会直连」「账号符合服务地区政策」当作三个独立结论。这是环境审查工具，不是账号注册、风控规避或付款代办服务。

## 先确认范围

- 从请求和已有上下文确定要检查的客户端（Desktop、Code、浏览器）与代理软件。只询问会改变检查或修改结果的缺失信息。
- 若这是为客户电脑提供远程服务，Skill 保留在服务提供者自己的 Codex 中，不要求客户安装。先标明当前助手运行在哪台电脑；本机终端或浏览器结果只能证明本机状态，绝不能当成远端客户设备的结果。只从客户授权的远控窗口、客户设备上的终端/浏览器或客户主动提供的截图取得客户设备证据，并在报告注明来源。远控不可可靠操作时引导客户执行、再核对结果。每项修改须由设备所有者确认。
- 首先确认使用地点是否在 Anthropic 当前支持范围内。若用户主要在不支持地区使用，应明确政策风险；不要将 IP、语言、时区或指纹伪装作为合规性的替代。
- 默认先只读检查。不要因第三方“防封教程”自动安装指纹浏览器、创建新账号、清理登录数据、改系统时区/地区/字体，或修改全机代理设置。
- 不索取或记录密码、验证码、Cookie、令牌和完整配置中的节点凭据。用户若要登录或付款，让其在官方界面自行完成敏感步骤；不要把聊天里曾出现的凭据输入任何地方。

## 检查与判断

按当前客户端和代理软件读取 [Mac 检查参考](references/mac-checks.md) 的相关部分，不必每次做所有测试。若用户引用“防封”文章或要评估其中做法，另读 [帖子经验核对](references/article-claims.md)，区分可测网络事实与未经证实的账号风控推断。

需要比较 GitHub/X 同类经验时，读 [补充资料核对](references/related-source-review.md)；只吸收能改变审查判断的步骤，不复制第三方代码或断言。

用户明确要求调整时区、Mac 地区或 Chrome 英语设置时，读取 [语言与时区模块](references/locale-and-language.md)。分别记录原值、修改目标和回退方式；不要把这些设置变化当作账号地区合规或风控通过的证据。

1. **本机客户端**：核实安装来源、版本、签名或完整性、CLI PATH/doctor、Desktop 与 CLI 各自的登录状态。不要把 Desktop 已登录推断为 CLI 已登录，也不要因网络可达推断为账号可用。
2. **正常连接**：核实当前 VPN 状态、默认路由、对外出口、DNS 路径和 Claude 服务的 TLS 连通性。无认证请求返回 401/405 等，只能证明到达服务，不能证明登录或订阅成功。WebRTC 测试只针对浏览器，不能替代 Desktop/CLI 的网络检查。
3. **断线行为**：分别检查节点失效、VPN 隧道意外断开、休眠或重启。记录代理规则、失败回退、自动重连、按需连接、睡眠断开及全流量入隧道等相关开关的实际值。不要把「自动重连」等同于「断线期间阻止直连」，也不要把一次正常连接测试说成故障测试。
4. **地区与账号风险**：当用户担心可用地区、订阅或封号，查 Anthropic 当前官方支持地区与政策。明确网络出口、系统语言/时区、旧 Google 邮箱或中文对话都不能保证账号不会受限制；不要给出无证据的封号概率或“防封”承诺。遇到 KYC、账单地址、付款拒绝，应走服务方的真实信息与官方支持流程，不指导绕过验证。

## 修改与复测

- 先做只读检查并列出候选变更。**每一项独立设置在执行前逐项确认**：写清当前值、目标值、影响范围、重启/断网可能性、备份与回退、验证方法；只接受该项明确答复。不把“全部按教程来”等笼统授权当作各项确认。用户已对同一具体变更完成逐项确认时不重复问；拒绝或跳过的项目不得执行。详见 [逐项确认协议](references/change-confirmation.md)。
- 修改设置、安装软件、清理数据、登录或付款不得借用另一项的确认。对外 IP 检测站会收到当前出口 IP，调用前也按其网站名称说明并确认。凭据、验证码和付款步骤交用户本人完成。
- 备份将被改动的配置并保留原文件；不要为一次检查自动修改全机网络、时区或浏览器语言。
- 只改能解决已证实问题的设置。路由或 DNS 修改后检查配置实际已生效，并至少验证 VPN 状态、出口、Claude 连通性和用户依赖的国内网站。全流量入隧道可能仍有系统服务例外，分流规则也可能有 DIRECT；如实描述。
- 故意断开 VPN 或使节点失效可能中断远程协助。只在用户明确要求故障模拟、可恢复路径已准备好时执行；否则标为「未实测」。故障后恢复原网络并核实结果。
- 第三方指纹浏览器、非官方补丁和“清号”步骤不是常规修复；如用户专门询问，分别评估来源、签名、隐私与账号政策，不将它们包装成必要条件。

## 交付

简洁列出：已观察到的状态、已执行的修改及备份/回退点、复测结果、未验证的故障场景、仍存在的服务地区风险。把实测、文档说明和推断分开。官方政策和软件行为会变化，引用前重新核对当前文档，例如 [Anthropic 支持地区](https://www.anthropic.com/supported-countries)、[Shadowrocket Wiki](https://github.com/LOWERTOP/Shadowrocket/wiki) 和 [Apple VPN 路由说明](https://developer.apple.com/documentation/networkextension/routing-your-vpn-network-traffic)。

需要保存正式报告时，使用 [报告模板](assets/report-template.md)，删除未检查的项目并遮盖个人数据；普通问答直接在对话中报告即可。
