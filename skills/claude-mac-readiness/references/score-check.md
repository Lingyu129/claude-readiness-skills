# 第三方分数与泄露检测

只有用户要求或同意外部检测时才打开。优先使用其实际访问 Claude 的浏览器；另一个浏览器的结果不可代替。访问检测站会向该站披露当前出口 IP 及浏览器特征，先说明准确域名、目的与数据并取得该站点的确认；不在客户未同意时批量打开多个检测站。

## 可选站点与记录

- [IPPure Claude 检测](https://ippure.com/claude)：记录页面当时显示的总分、满分/方向、连通性、出口、WebRTC、DNS、语言、Intl 时区、字体/Emoji 等实际出现的提示。
- [Net.Coffee Claude 检测](https://ip.net.coffee/claude/)：可作为另一个独立检测；其 Trust Score 与 IPPure 的分数定义不同，不合并、平均或直接比较。

每次记录站点、检测时间、浏览器、是否启用 VPN/TUN、总分与各项原文标签的简短转述。只在报告中保留国家/地区、ASN、是否有真实 IP 泄露等必要摘要；不保存完整公网 IP、WebRTC candidate、浏览器指纹载荷或站点生成的私人链接。若页面没给分数，写“未显示”，不能补造。

## 如何解读

1. 优先核实可复现的事实：是否意外显示真实公网 IP，DNS 请求路径是否符合预期，Claude 网页是否可达，终端出口是否另有路径。
2. 语言、时区、字体和 Emoji 是设备/浏览器特征；检测站对它们的扣分属于其自行设定的启发式评分。IPPure 关于 Claude 内部遥测或封号因果的说法不是 Anthropic 官方证据，不作为修改系统的依据。
3. 高分不证明账号合规或不会被封，低分也不等于账号会被封。WebRTC/DNS 警告要结合浏览器权限、TUN、代理规则与复测解释。
4. 修改确有问题的设置后，在同一浏览器、同一站点复测，列出前后分数及具体变化。不要为了“刷分”自动删除系统字体、伪装身份、改虚假地区或关闭无关安全功能。
5. 第三方网页只测试它所在的浏览器；Claude Code CLI 和 Desktop 的路由、认证及服务地区政策仍需单独验证。
